RR — Personal Drive Connector

RR is a personal-use configuration for connecting the open-source rclone tool to Google Drive using OAuth 2.0.

It allows the account owner to authorize access to their own Google Drive and initiate file listing, upload, download, and synchronization between their own configured storage locations.

RR does not offer a public file-storage service. This website is an informational page only: it does not receive Google credentials, OAuth tokens, or Drive file contents.
